# saas_core architecture (module contract). No product-specific (customer/brand) code anywhere; enforced in CI by `scripts/check_no_product_names.sh`.
Python pkg root: `saas_core/` (this dir) -> `saas_core/saas_core/doctype/<snake>/` for DocTypes (module "Saas Core", dir `saas_core/saas_core`).
Tests: pure-python `tests/` (frappe faked by tests/frappe_stub.py via autouse `frappe` fixture; import saas_core modules INSIDE tests/functions after the fixture runs, or at module level in a way that survives re-import). Bench-only tests in `tests/frappe_tests/` (FrappeTestCase, never collected by pytest: name files `bench_*.py`). Run: `/private/tmp/claude-501/venv/bin/pytest tests -q` (has pytest, pyyaml).
Style: Python 3.10+, type hints, tabs NOT required (use 4 spaces), no network calls at import, no secrets. Each module has a docstring. Never call a real gateway/FC: everything behind an injectable port with a fake.

## Cross-module interfaces (exact)
- `saas_core.audit.log(action:str, *, actor:str|None=None, target_doctype=None, target=None, details:dict|None=None) -> str` creates hash-chained Audit Event (D).
- `saas_core.jobs.enqueue_job(tenant:str, kind:str, *, args:dict|None=None, approval:str|None=None, dedupe_key:str|None=None) -> str` creates Provision Job (state pending) + `frappe.enqueue("saas_core.provisioning.runner.run_job", job=name)`; returns job name; if dedupe_key matches a non-terminal job returns that one (D).
- `saas_core.events.publish(type:str, *, tenant=None, job=None, data=None) -> None` (lead; no-op safe).
- `saas_core.gateways.registry.get_gateway(name:str, account:str|None=None) -> Gateway` (B). Gateway ABC: `create_checkout_session(CheckoutParams)->CheckoutResult`, `portal_link(customer_ref, return_url)->str`, `cancel_subscription(sub_ref, at_period_end)->None`, `verify_webhook(headers:dict, raw_body:bytes)->bool`, `parse_event(payload:dict)->NormalizedEvent`. `NormalizedEvent(dataclass)`: `event_id, gateway, kind, subscription_ref, customer_ref, tenant_ref(metadata tenant name), amount:int, currency, period_end:datetime|None, invoice_ref, raw:dict`. kinds: `checkout.completed|payment.succeeded|payment.failed|subscription.canceled|subscription.updated|refund|ignored`.
- `saas_core.webhooks.<gateway>()` whitelisted allow_guest: verify -> `ingest(gateway, headers, raw_body)` -> insert Payment Event (unique name `<gateway>:<event_id>`; duplicate => status "duplicate", no-op) -> `frappe.enqueue("saas_core.billing.processor.process_payment_event", event=name)`.
- `saas_core.billing.processor.process_payment_event(event:str)`: loads Payment Event, applies to Subscription/Invoice (create on checkout.completed), calls dunning, on first success of a pending tenant calls `jobs.enqueue_job(tenant,"provision",dedupe_key=...)`; marks event processed/failed (idempotent).
- `saas_core.billing.dunning`: `on_payment_failed(subscription)`, `on_payment_succeeded(subscription)`, `run_daily()`; stages from DUNNING_SCHEDULE (days after first failure: [1,3,7,14] -> stage 1..4; stage 3 => suspend via `jobs.enqueue_job(t,"suspend")`; payment success => `resume`).
- `saas_core.billing.entitlements.can_create_tenant(user, plan)->(bool,reason)`, `capacity_open()->bool`.
- `saas_core.permissions`: `tenant_query(user)`, `subscription_query`, `invoice_query`, `job_query`, `ticket_query`, `has_tenant_permission(doc,ptype,user)`, `has_tenant_child_permission`, `has_ticket_permission` (A2). `assert_tenant_access(tenant_name, user=None, ptype="read")->Document` raises DoesNotExistError (404, to avoid enumeration) if not owner and not SaaS Admin/System Manager.
- `saas_core.provisioning.ports`: Protocols `SessionStore, Journal`, `FcctlPort` (`provision_site(spec)->RunResult`, `suspend_site`, `resume_site`, `terminate_site`, `create_backup`, `list_backups`, `backup_download_link`, `login_link`, `change_plan`). `fake_fcctl.FakeFcctl` implements it deterministically with failure injection. Real adapter `stores.py` lazily imports `fcctl`.
- Recipes: entry-point group `saas_core.recipes` -> class with `slug`, `template_defaults()`, `hooks()->dict[name@ver, callable]`, `tenant_config(tenant, plan, fields)->dict`, `signup_schema()->dict`. `recipes.registry.get(slug)`, `.all()`.

## Common API conventions (E1/E2; helpers in api/v1/_common.py owned by E1)
- Response: return payload from `@frappe.whitelist()` fn (Frappe wraps as {"message":..}). Errors: raise `ApiError(code, message, http_status, field_errors)`; `_common.install_error_handler` not needed -- set `frappe.local.response["http_status_code"]` and return/raise per `_common.error_response`. Codes per openapi/v1.yaml Error schema.
- Paging: `paginate(doctype, filters, fields, cursor, limit, order_by="creation desc")->{"items","next_cursor"}`; cursor = opaque base64 of offset (simple).
- Idempotency: `_common.idempotent(key, request_hash, fn)` backed by frappe cache (24h); mismatch => 409 `idempotency_mismatch`.
- Rate limit: `_common.rate_limit(key, limit, window)`; 429.
- Serializers: `to_tenant(doc)`, `to_job(doc)`, etc in `_common.py`-adjacent `serializers.py` (E1 owns `api/v1/serializers.py` for ALL serializers; E2 imports them; E1 must deliver serializers FIRST-class in `_common.py`/`serializers.py` matching openapi schemas exactly).
- Endpoint placement RULE: operation path `saas_core.api.v1.<dotted>.<fn>` => `def <fn>` (decorated `@frappe.whitelist()`, or `allow_guest=True` for public) in module `saas_core/api/v1/<dotted as path>.py`, e.g. `plans.list` -> api/v1/plans.py `def list`; `tenants.backups.list` -> api/v1/tenants/backups.py; `support.tickets.create` -> api/v1/support/tickets.py; `password_reset.request` -> api/v1/password_reset.py; `checkout.create_session` -> api/v1/checkout.py. Packages `tenants/` and `support/` have `__init__.py` holding their own top-level ops (tenants.list/get/create/request_delete/suspend_status/open_login_link). Shadowing builtin `list` inside those modules: use `import builtins` where needed. Params are plain function args matching the OpenAPI query/body names; POST bodies arrive as form_dict kwargs.
- `invoices.pdf` and `events.stream` return non-JSON (events owned by lead).

## DocType fields (snake_case; all modules must use exactly these)
- Tenant (autoname field:slug): slug, owner_user(Link User), status(Select pending/provisioning/active/suspended/terminating/failed), plan(Link Plan), template(Link Template), region, fc_server_id, fc_site, custom_domain, created_via, suspend_reason, active_job, workflow_id, recipe_fields(JSON). Permission: owner_user.
- Plan (autoname field:code): code, title, description, is_public, available, trial_days, fc_server_plan, limits(JSON), template(Link), features(JSON list), prices(Table Plan Price: interval, currency, amount, gateway, gateway_price_id), sort_order.
- Subscription (naming SUB-.#####): tenant, owner_user, plan, gateway, gateway_sub_id, gateway_customer_id, interval, currency, status(trialing/active/past_due/canceled), period_end, trial_end, cancel_at_period_end, dunning_stage(Int), first_failure_at, last_event_at.
- Invoice (naming INV-.#####): tenant, owner_user, subscription, gateway, gateway_invoice_id, number, status(draft/open/paid/void/uncollectible/refunded), total_amount(Int minor), currency, issued_at, paid_at, period_start, period_end, pdf_url.
- Payment Event (autoname field:event_key): event_key (`<gateway>:<event_id>`), gateway, event_id, kind, status(received/processing/processed/failed/ignored), raw_payload(Code JSON), subscription_ref, tenant_ref, error, processed_at, attempts.
- Gateway Account (naming field:account_name): account_name, gateway, mode(test/live), enabled, key_id, key_secret(Password), webhook_secret(Password), extra(JSON).
- Template (autoname field:slug): slug, title, description, is_public, min_plan(Link Plan), recipe, apps(Table Template App: app, source_repo, branch, version, install_order), backup_source(JSON: profile/site/backup | bucket_key), hooks(JSON list of {name,version,args}), sanitize_config(JSON), health_checks(JSON), site_config(JSON).
- Provision Job (naming PJ-.######): tenant, kind(provision/suspend/resume/change_plan/terminate/backup/restore), state(pending/dispatching/submitted/running/succeeded/failed/stuck/outcome_unknown/needs_attention), workflow_id, attempts, needs_attention(Check), error, args(JSON), approval(Link Approval Request), dedupe_key, steps(Table Provision Job Step: seq, name, state, hook_version, started_at, finished_at, message, handle), finished_at.
- Support Ticket (naming TKT-.#####): tenant, owner_user, subject, body, status(open/pending/resolved/closed), priority, replies(Table Support Ticket Reply: from_staff, body, at, author).
- Audit Event (naming AUD-.#########, immutable): seq(Int), at, actor, action, target_doctype, target, details(JSON), prev_hash, hash.
- Approval Request (naming APR-.#####): op, target, args(JSON), digest, requested_by, approved_by(JSON list), status(pending/approved/executing/executed/failed/expired/outcome_unknown), expires_at, journal_id, blast_radius(JSON). Two-person: approver != requester, role SaaS Admin; `require_approvers` default 2 (setting in `Single`? no: constant APPROVALS_REQUIRED in provisioning/ports.py).
- Platform Session (naming field:login): login, blob(Password, Fernet-encrypted by key from site_config `saas_core_session_key`), version(Int). Roles: only "SaaS Platform Worker"/System Manager have read perm; web role "SaaS Customer"/Guest none.
