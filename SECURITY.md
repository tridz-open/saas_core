# Security policy

saas_core is early alpha software, provided "as is" without warranty of any kind (see [LICENSE](LICENSE)).

## Reporting a vulnerability

Please report security issues **privately**, not in public issues. Use GitHub's private vulnerability reporting: open the repository's **Security** tab and click **Report a vulnerability**
(<https://github.com/tridz-open/saas_core/security/advisories/new>).

Include the version or tag, what you did, what you expected and what happened. We aim to acknowledge within 7 days.

## Scope

saas_core is a SaaS control plane that handles signup, payments (Razorpay) and tenant provisioning. Alpha: run it on test-mode payment keys only. Never include real keys, tokens or customer data in a report.
