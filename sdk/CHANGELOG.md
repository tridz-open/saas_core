# Changelog

Per-package changelogs are generated by [changesets](https://github.com/changesets/changesets) and live in
`packages/*/CHANGELOG.md`. All packages share one version.

## Merged into saas_core (0.1.0-alpha.4)

The SDK now lives in `sdk/` of [tridz-open/saas_core](https://github.com/tridz-open/saas_core) and is released with it.

- All `@frappe-saaskit/*` packages bumped to `0.1.0-alpha.4`; package names unchanged.
- `repository` now points at `tridz-open/saas_core` (`directory: sdk/packages/<name>`).
- Codegen reads `../openapi/v1.yaml` directly. Removed `spec/` and `pnpm spec:sync`.
- Tarballs are attached to saas_core GitHub releases, not to `frappe-saaskit-sdk` releases. SECURITY, CONTRIBUTING and the issue/PR templates are the repo-root ones.
- History before this point was imported with `git subtree`, so older entries refer to the former repository.
